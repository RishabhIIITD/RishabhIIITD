### 🚀 High-Impact Projects

#### [🤖 AI-Interviewer — Educational Concept Validation](https://github.com/RishabhIIITD/AI-Interviewer)
*An AI-powered platform for in-class concept validation and post-class interview practice.*
- **The Challenge:** Scaling 1-on-1 technical interviews and concept checks in a large-scale EdTech environment.
- **The Solution:** A cross-platform application (Electron + React) featuring a **Dual LLM Engine** (Gemini/Ollama) with real-time voice interaction (STT/TTS) and detailed performance analytics.
- **Impact:** Enables students to receive instant, objective feedback on technical discussions and project defense readiness.
- **Tech:** React • TypeScript • Electron • Express • Drizzle ORM • Google Sheets API

#### [🎓 Admin Panel for MCQs — Content Management at Scale](https://github.com/RishabhIIITD/Admin-Panel-for-Questions)
*Modern admin portal for creating and managing complex MCQs with LaTeX support.*
- **Highlight:** Built a high-performance CMS using **Next.js 15** that leverages Google Sheets as a real-time, zero-maintenance database.
- **Innovation:** Supports live rendering of **Markdown + LaTeX** math equations, difficulty categorization, and automated contest JSON generation.
- **Impact:** Streamlined the question creation workflow for content teams at upGrad School of Technology.
- **Tech:** Next.js 15 • Tailwind CSS • Google Sheets API • Zod • KaTeX

#### [✅ Hintify — The "Anti-ChatGPT" Learning Assistant](https://github.com/RishabhIIITD/Hintify)
*Solving the "Copy-Paste" problem in modern education.*
- **The Solution:** A vision-capable assistant that extracts text from screenshots and provides **Socratic hints** instead of direct answers.
- **Impact:** Used to guide students through complex problem-solving without stripping them of the learning experience.
- **Tech:** Ollama • Gemini Vision API • Tesseract OCR • Python

#### [✅ Enterprise Multi-Video RAG Engine](https://github.com/RishabhIIITD)
*Contextual intelligence for massive video repositories.*
- **Highlight:** Built a dual-response system that cross-references video transcripts with general LLM knowledge to eliminate hallucinations.
- **Tech:** Whisper • FAISS • LangChain • Streamlit • Python
